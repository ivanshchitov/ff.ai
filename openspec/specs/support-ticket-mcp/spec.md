# support-ticket-mcp Specification

## Purpose
Обеспечивать чтение JSON с обращениями поддержки через MCP: отдавать выбранный тикет
и связанного пользователя с ограниченным набором полей и явными ошибками данных.

## Requirements

### Requirement: Ограниченное чтение обращения через MCP

MCP-сервер SHALL предоставлять инструмент получения контекста по идентификатору тикета
из явно выбранного локального JSON. Он SHALL возвращать только этот тикет и связанного
пользователя, идентификатор и источник данных. Сервер SHALL перечитывать данные при
каждом вызове, иметь только инструменты чтения и не изменять JSON или проект.
Допустимые поля SHALL ограничиваться идентификаторами, статусом, темой, описанием,
кодом ошибки, версией продукта, провайдером авторизации и безопасными атрибутами пользователя.
Неизвестные поля, контактные данные и учётные секреты SHALL исключаться;
распознаваемые секреты в свободном тексте SHALL скрываться до возврата результата.

#### Scenario: Выбранный тикет и его пользователь
- **WHEN** MCP получает идентификатор существующего тикета
- **THEN** результат содержит выбранный тикет и его пользователя без чужих записей,
  секретных или неизвестных полей и без изменения файла данных

#### Scenario: Свежие данные
- **WHEN** содержимое JSON изменено после предыдущего вызова
- **THEN** новый вызов возвращает обновлённый контекст

### Requirement: Проверка входа и данных до доставки

Сервер SHALL отклонять отсутствующий файл, симлинк, файл сверх лимита, некорректный JSON,
неверную схему, дубли идентификаторов, неизвестный тикет, отсутствующего связанного
пользователя и результат сверх лимита. Идентификатор тикета SHALL NOT использоваться
как путь файла. Ошибки SHALL возвращаться как ошибки инструмента с понятной причиной,
без вывода сырого JSON, секретов и содержимого посторонних файлов.

#### Scenario: Неизвестный идентификатор
- **WHEN** запрошен неизвестный тикет или отсутствует его пользователь
- **THEN** MCP возвращает явную ошибку инструмента и не выбирает другую запись

#### Scenario: Непригодный источник
- **WHEN** файл недоступен, является симлинком, превышает лимит или нарушает схему
- **THEN** сервер отказывает с причиной без доставки частичных данных

#### Scenario: Идентификатор похож на путь
- **WHEN** аргумент содержит путь к файлу вместо допустимого идентификатора
- **THEN** сервер отклоняет аргумент и не открывает этот путь
