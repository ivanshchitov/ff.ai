# Решения фазы P2

## Векторы считаются на месте, а не хранятся

Поиск по коду локальный: векторы фрагментов считаются из их текста при поиске. Хранить их в
индексе значило бы решать за фазу P10 (локальные embeddings), где вектор становится свойством
модели и его придётся пересобирать при её смене. Хеширование токенов в вектор — приближение, а не
семантика, и это честно: для кода идентификаторы (`ModelList`, `qmake`, `Q_PROPERTY`) важнее
синонимов, а точное совпадение имени метода — сильный сигнал. Минус у приближения один — нет
морфологии; его закрывает вторая ступень, которую можно спросить словами.

## Две ступени, как у документации, но с общим кодом второй ступени

`baseline` — это «показать первые результаты поиска»: без порога и без вспомогательных запросов.
`enhanced` — переформулировка вопроса, пул кандидатов, оценка каждого моделью, порог. Вторая
ступень уже написана для документации, и её же комментарий говорит, что инструкция «одинакова для
всех корпусов»: поэтому модуль переименован из `docs_reranking` в `reranking`, а инструкция стала
параметром с прежним значением по умолчанию. Поведение документации не меняется — это проверяется
её же тестами.

## Гейт «не знаю» — только для enhanced

Если кандидаты есть, но все ниже порога, вопрос остаётся без ответа по памяти: это ровно тот
случай, когда модель уверенно сочинит метод, которого нет. В `baseline` порога нет, поэтому исход
недостижим; отсутствие кандидатов и отсутствие индекса — другие состояния и ведут себя как раньше.

## Пулы ограничивают и запрос, и доставку

`before` ограничивает, сколько кандидатов вообще показывать оценщику (иначе на большом репозитории
в один запрос уедут сотни фрагментов), `after` — сколько пройдёт в ответ. Оба значения меняются
атомарно: негодная пара (`after` больше `before`, порог вне диапазона) не должна оставить сессию
в половинчатом состоянии.

## Проверка цитат общая, различается минимум длины

Механизм подтверждения уже общий: «назови доставленный идентификатор и приведи дословный
фрагмент». Для кода строка вроде `void Window::open()` короче двадцати символов, поэтому минимум
длины цитаты для корпуса кода выше: короткая цитата кода подтверждает что угодно и ничего не
доказывает. Инструкция цитат и текст замены остаются общими — смешанный вопрос (код и платформа)
доставляет фрагменты обоих корпусов в одном сообщении, и одна конвенция понятнее двух.

## Что видит пользователь при сбое оценки

Негодный ответ оценщика — не повод отвечать сырыми кандидатами: тогда в ответ уехал бы шум под
видом отбора. Состояние снимка называет сбой, вопрос идёт без фрагментов кода, и это видно в
`/code trace`.
