# Тонкий web-фронтенд

## Why

Терминал удобен для работы, но ответы с цитатами, диффы патчей и панель задачи удобнее смотреть в
браузере, где есть прокрутка, раскрывающиеся фрагменты и кнопки подтверждения.

## What Changes

- `web/app.py`: приложение FastAPI над фасадом сессии — вопрос, команды, отчёты из снимков, поток
  событий (SSE), подтверждения патчей и необратимых шагов, запуск прогона задачи.
- `web/static/`: страница, скрипт и стиль без сборщика и без внешних источников.
- Флаг `--web` с адресом и портом; зависимости `fastapi` и `uvicorn`.

## Impact

- Новые файлы: `web/**`, тесты.
- Правки: `ff-ai.py` (флаг), `requirements.txt`, документация.
- Терминальный интерфейс остаётся прежним: web-слой работает над тем же фасадом.
