# Решения фазы P11

## Один фасад — два интерфейса

Web-слой вызывает те же методы фасада, что и терминальные панели: второго набора логики нет, и
поведение в браузере и в терминале не расходится. Отчёты — из снимков, поэтому открытая страница не
может случайно дёрнуть модель.

## Подтверждение — брокер с таймаутом

Фасад принимает обработчики подтверждения; web-слой подставляет брокер, который публикует запрос в
поток событий и ждёт ответа. Отсутствие ответа — отказ: у ожидания объявленный бюджет.

## Без сборщика и без CDN

Статика — три файла, никаких внешних источников: страница обязана работать в закрытом контуре, и
тест это проверяет. Чужие тексты попадают в DOM только как текст.
