# Локальные векторы в поиске по коду

## Why

Поиск по коду ищет по совпадению токенов: вопрос и фрагмент должны разделить буквальные слова.
Русский вопрос не находит ничего в англоязычном коде — в живом прогоне его вытягивал только
отдельный запрос-переформулировка, который модель выполняла на каждый вопрос. Локальные эмбеддинги
(фаза P10) уже реализованы и проверены, но в индексе кода не используются.

## What Changes

- `core/code_index.py`: таблица векторов фрагментов рядом с фрагментами; версия схемы поднимается —
  индекс без векторов честно перестаёт читаться, и его пересобирают командой.
- Сборка индекса принимает провайдера эмбеддингов: векторы считаются внутри временной базы до
  атомарной замены, поэтому индекс не бывает полувекторизованным; сбой эмбеддингов отменяет сборку и
  оставляет прежний индекс нетронутым.
- `core/code_retrieval.py`: ранжирование по косинусу векторов, когда векторы для модели есть; токенный
  путь остаётся явным режимом, и сравнение двух способов видно в отчёте.
- Отсутствие локального сервера — названная причина в отчёте поиска, а не молчаливый переход к токенам.

## Impact

- Правки: `core/code_index.py`, `core/code_retrieval.py`, при необходимости `core/embeddings.py`
  (только добавления), `core/session.py` (строка отчёта), тесты.
- Индекс после обновления собирается заново: схема изменилась.
