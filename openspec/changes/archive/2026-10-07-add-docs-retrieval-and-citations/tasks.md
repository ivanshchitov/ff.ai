## Заметки фазы

- **Поиск по документации — одна сессия соединения на поиск.** Одноразовый вызов поднимает
  серверный процесс заново: без сессии поиск стоил 21 с вместо 3–6 с (пять инструментов на вопрос).
  `MCPClient.session()` держит соединение на время операции; тестовая заглушка ретривера получила
  тот же метод, потому что контракт клиента изменился.
- **Проверка ссылок работает только для свободного формата**, а единственная форма ответа без
  ссылки — явный отказ «Документация не относится к вопросу»: домен разрешает смежные вопросы
  (уровень 3), и без этой развилки проверка заменяла бы полезный ответ отказом.
- **Шум поиска — открытый вопрос.** В контрольном прогоне из трёх доставленных фрагментов релевантен
  был один: портал ранжирует сам, а фрагменты отбираются без второй ступени. Реранкинг моделью
  (вторая ступень отбора) — кандидат на отдельное изменение; в P4 сознательно не делался.
- **Вопрос о версии не попал в раздел примечаний к выпуску**: слова-признаки из пакета сработали,
  но поиск по `release_notes` не дал попаданий, которые обошли бы `docs`. Модель ответила честно,
  однако ожидание «ответ по примечаниям» не выполнено — это тоже аргумент за реранкинг или за
  автовызов инструментов моделью (P5).
- **Стоимость**: восемь контрольных вопросов — ≈0,002 $ и 5–10 с на ответ, из них 3–6 с — поиск.
