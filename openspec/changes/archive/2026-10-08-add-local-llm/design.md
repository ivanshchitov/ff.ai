# Решения фазы P10

## Адрес берётся из конфигурации

Базовый адрес выводится из адреса локального чата, а не задаётся вторым литералом: иначе сервер
слушал бы не там, куда уходят запросы локальных пресетов.

## Значения по умолчанию не замерзают

Путь к скрипту, адрес, лог и бюджет ожидания берутся в момент вызова: пути состояния — свойство
запуска, а не импорта.

## Чужой слушатель не трогается

Перед запуском адрес проверяется: отвечающий сервер переиспользуется, чужой процесс не
останавливается, своя группа процессов убирается при выходе.

## Откат на хеш-векторы не переносится

Сбой эмбеддингов — ошибка с причиной. Поиск по коду продолжает работать своим токенным путём, но
подмена векторов не выдаётся за результат модели.
