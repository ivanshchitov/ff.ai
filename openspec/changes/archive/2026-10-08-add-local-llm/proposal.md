# Локальная LLM и локальные embeddings

## Why

Облачная модель стоит денег, требует ключа и сети. Локальная не требует ничего, кроме железа
(и весов), и нужна для режима без ключа, для приватных репозиториев и для офлайна.

## What Changes

- `core/llama_server.py`: поиск уже отвечающего слушателя, запуск сервера в своей группе процессов,
  ожидание готовности, остановка при выходе и по сигналам, логи рядом с модулем.
- `llama_server/models.ini` и `server.sh`: пресеты под код (чат и embedding).
- `core/embeddings.py`: локальные эмбеддинги с нормализацией и проверкой размерности.
- Локальный режим без облачного ключа; автозапуск выключается переменной окружения.

## Impact

- Новые файлы: `core/llama_server.py`, `core/embeddings.py`, `llama_server/models.ini`,
  `llama_server/server.sh`, тесты.
- Правки: `ff-ai.py` (жизненный цикл), `core/session.py` и `ui/tui_app.py` (ключ не нужен локальной
  модели), `ui/models_screen.py` (локальные пресеты в списке), `.env.example`, документация.
