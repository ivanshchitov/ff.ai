## Заметки фазы

- **Поиск локальный, векторы — разреженные.** Токены, idf по корпусу, косинус: без сети и без
  модели, детерминированно и проверяемо. Фрагмент без единого общего токена с запросом не
  считается кандидатом вовсе — платить модели за оценку такого не за что.
- **Русский вопрос по английскому коду не находит ничего** — это не дефект, а причина, по которой
  режим `enhanced` переформулирует вопрос. Тест это фиксирует явно: `baseline` на русский вопрос
  не находит кандидатов, а тот же вопрос с переформулировкой находит нужный файл.
- **Живой прогон нашёл две правки правила цитат.** Модель называет файл без диапазона строк
  (`src/arguments-receiver.cpp`) — источник теперь опознаётся и по одному пути; короткий
  QML-фрагмент нельзя было подтвердить цитатой в 40 символов — теперь фрагмент короче минимума
  подтверждается цитатой целиком. Оба случая закрыты тестами и повторным живым прогоном, где оба
  ответа подтверждены.
- **Состояние «ниже порога» — инструкция модели, а не жёсткий отказ**: так это устроено у
  документации, и второй корпус не должен вести себя иначе.
- **Сквозной тест поймал выход в сеть**: с пустым переопределением MCP домен подключал настоящий
  сервер документации. Записано в грабли `AGENTS.md`.
- **Шаблон `.env.example` — единственное описание настроек**: девять новых переменных корпуса кода
  добавлены туда, и это проверяет существующий тест.
