# Задачи

## 1. Корпус и обход

- [x] 1.1 Тесты отбора файлов: расширения домена, исключения, предел размера, двоичные файлы, `.gitignore`
- [x] 1.2 Обход через `git ls-files` в git-репозитории и обычным обходом вне git; в отчёте виден способ
- [x] 1.3 `/code index` не создаёт в целевом репозитории ни одного файла

## 2. Разбиение

- [x] 2.1 `fixed`: окна строк с перекрытием, границы по строкам, последний фрагмент без хвоста
- [x] 2.2 `structural`: начало блока по правилам домена, склейка мелких блоков, потолок размера, крупный блок режется
- [x] 2.3 Инвариант: строки файла по диапазону фрагмента совпадают с его текстом

## 3. Хранилище

- [x] 3.1 SQLite-схема: фрагменты (стратегия, идентификатор, путь, строки, текст, хеш) и метаданные
- [x] 3.2 Путь в кэше состояния по хешу пути репозитория; переопределение переменной окружения
- [x] 3.3 Атомарная замена: сбой сборки не затирает прежний индекс
- [x] 3.4 Снимок сборки: число файлов, фрагментов, пропусков по причинам, время сборки

## 4. Команды и интерфейс

- [x] 4.1 `/code index [fixed|structural]`, `/code status`, `/code compare` без обращений к модели
- [x] 4.2 Отчёт кэшируется в фасаде, строки отчёта попадают в журнал и в панель команд

## 5. Сквозные проверки

- [x] 5.1 e2e: `/code index` на временном проекте под Аврору, `/code status` с путём в кэше, репозиторий не изменён
- [x] 5.2 e2e: `/code compare` печатает обе стратегии с диапазонами; `/usage` подтверждает ноль обращений к модели
- [x] 5.3 e2e: сбой сборки (недоступный каталог) оставляет прежний индекс

## Заметки фазы

- **Разбиение по строкам, а не по символам.** Цитата в этой области — `path:L10-L40`; разбиение по
  символам пришлось бы пересчитывать в строки, а пересчёт расходится с файлом на каждой правке.
  Тест сверяет диапазон фрагмента с содержимым файла — это ловит расхождение нумерации.
- **Правила отбора проверены на живом проекте.** На пакете `aurora-qt5` корпусом признаются
  `.cpp/.h/.qml/.pro/.spec/.cmake/…`, а `build/`, `vendor/`, `*.lock`, двоичные и крупные файлы
  пропускаются с причиной: `/code status` печатает сводку причин, а не список.
- **Предел размера включительный**, а расширение проверяется раньше правил исключения: порядок
  проверок — от дешёвой к дорогой, и это видно в тестах (`.lock`-файл попадает в «расширение вне
  корпуса», а не в «исключён правилами»).
- **Сбои сборки не разрушают прежний индекс** — проверено и юнитом (провал `os.replace`), и e2e
  (каталог на месте временного файла): прежний индекс остаётся пригодным, временный файл убирается.
- **В e2e демонстрационный проект обязан быть git-репозиторием**: иначе приложение не стартует
  («каталог не является git-репозиторием»), а корпус к тому же берёт список файлов у git.
- **Документация перепроверена, а не дописана**: в `docs/domains.md` раскладка пакета была из
  раннего плана (`*.yaml`) и не совпадала с фактическими `*.json` — приведена к факту, отсутствующие
  разделы (память, профиль, проверки) названы будущими фазами.
