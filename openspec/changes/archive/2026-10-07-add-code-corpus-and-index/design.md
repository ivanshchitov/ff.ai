# Решения фазы P1

## Фрагмент — строки файла, а не символы

Цитата в этой предметной области — `path:L10-L40`, то есть строки. Разбиение по символам
пришлось бы пересчитывать в строки, а пересчёт расходится с файлом на каждой правке и врёт в
цитате. Поэтому у фрагмента две координаты — путь и диапазон строк, — и текст всегда дословный
кусок файла по этому диапазону. Тест сверяет диапазон с содержимым файла: это дешёвая проверка,
которая ловит расхождение нумерации.

## Правила отбора — данные домена

Расширения исходников, каталоги сборки, признаки договорных файлов и границы блоков принадлежат
предметной области, а не ядру: у другой платформы будет другой набор. Это тот же инвариант, что
для инструментов и разделов документации, и он проверяется тестом «в `core/` и `ui/` нет
идентификаторов домена». Правила живут в `domains/<id>/corpus.json`: расширения, исключения,
предел размера файла, потолок и перекрытие окон, признаки начала блока по расширению.

## `.gitignore` читается через git, а не переписывается регулярками

Свой разбор `.gitignore` — это источник тихих расхождений (вложенные файлы, отрицания, шаблоны
каталогов). Если целевой репозиторий под git, список файлов даёт
`git ls-files --cached --others --exclude-standard`: он и учитывает игнорирование, и не спускается
в каталоги сборки. Вне git используется обычный обход с исключениями домена, и отчёт говорит,
каким способом получен список.

## Индекс — кэш, а не данные пользователя

Индекс производён от репозитория и восстанавливается одной командой, поэтому он лежит в кэше
состояния (`$XDG_CACHE_HOME/ff-ai/<хеш пути>/code-index.sqlite3`), а не в данных и тем более не в
репозитории. Хеш пути разводит проекты: два репозитория не делят один индекс, а перенос каталога
даёт новый индекс вместо устаревшего. Переменная окружения переопределяет путь — это нужно и
тестам, и работе с несколькими копиями одного проекта.

## Замена индекса — атомарная

Сборка пишет новый файл рядом и заменяет прежний одним `os.replace` только после успешной записи.
Иначе обрыв на середине (нет прав, кончилось место, исключение в разборе) оставил бы пользователя
с полупустым индексом и без прежнего — а прежний ещё пригоден.

## Поиска в этой фазе нет

Фаза даёт корпус: файлы, фрагменты, диапазоны. Ранжирование, режимы отбора, порог и обязательные
цитаты — P2, и там же решается, какие векторы использовать (в доноре облачные модели считали
хеш-векторы по тексту фрагмента, локальные — хранились в индексе). Смешивать это с P1 значило бы
проектировать поиск, не имея корпуса на руках.

## Команда называется `/code`

`/docs` уже занята документацией портала (режим, версия, трассировка, режим отбора, порог) и
описана в README и e2e. Отдавать тот же префикс второму корпусу — значит ломать существующее
поведение ради экономии одного слова; `/code` разводит корпуса по предмету и не трогает занятое.
