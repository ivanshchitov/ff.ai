# Корпус кода целевого репозитория и индекс

## Why

Ассистент отвечает по документации портала и умеет искать по репозиторию инструментами
(`repo_search`, `repo_read`), но собственного корпуса кода у него нет: поиск по репозиторию — это
поиск по строкам, он не знает ни структуры файлов, ни границ блоков, а значит не может ни
ранжировать найденное, ни сослаться на диапазон строк. Фаза P2 (поиск по коду и обязательные
цитаты `path:L10-L40`) без этого корпуса не реализуема, а P4 явно отложила её сюда.

Индекс — производное данных репозитория, а не новая память: он строится по команде, лежит в кэше
состояния, ничего не пишет в целевой репозиторий и может быть удалён без последствий. Поэтому
он строится ровно тогда, когда о нём просят, и не перестраивается на старте.

## What Changes

- `core/code_index.py`: обход целевого репозитория с учётом `.gitignore`, двоичных файлов, крупных
  файлов и исключений пакета домена; две стратегии разбиения (`fixed` — окна строк с перекрытием,
  `structural` — границы по структуре файла); фрагмент — путь и диапазон строк.
- Хранилище — SQLite в кэше состояния по хешу пути репозитория, с переопределением переменной
  окружения; путь печатает `/code status`.
- Сборка идёт во временный файл и заменяет прежний индекс только при успехе: ошибка обхода не
  должна оставить пользователя без рабочего индекса.
- Команды `/code index [fixed|structural]`, `/code status`, `/code compare` — отчёты без обращений
  к модели.
- Пакет домена объявляет корпус: расширения, исключения, потолок размера файла и границы структуры
  (`domains/aurora-qt5/corpus.json`).

## Impact

- Новые файлы: `core/code_index.py`, `domains/aurora-qt5/corpus.json`, `tests/unit/test_code_index.py`,
  `tests/e2e/test_code_index_flow.py`.
- Правки: `core/config.py` (путь индекса и переменная окружения), `core/session.py` (`/code …` и
  отчёты), `ui/tui_app.py` (строки отчёта и панель команд), `core/domains.py` (загрузка корпуса),
  `tests/e2e/harness.py` (изоляция пути индекса), документация.
- Поиск по индексу (retrieval и цитаты) в этой фазе не делается — это P2.
