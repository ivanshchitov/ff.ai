## Why

День 34 требует доказать реальную работу ассистента с несколькими файлами по цели пользователя.
У ff.ai уже есть чтение через MCP и конвейер подтверждённых патчей, но нет воспроизводимого сценария этой задачи на WebDavClient.

## What Changes

- Кодовый сценарий выполнять тремя небольшими подзадачами: контроллер, тест, документ, с отдельным ревью и подтверждением каждой.
- Добавить воспроизводимый запуск трёх сценариев: исследование использования компонента, создание документа и защита создания папки от повторного запуска.
- Использовать временную копию WebDavClient и изолированное состояние; сохранить ответы, источники, diff и результаты проверок вне исходного проекта.
- Встроить субагентов разработчика и независимого ревьюера с отдельными контекстами, ограниченным исправлением замечаний, показом ролей и учётом каждого запроса.
- Детерминированно проверять патч до ревью; не применять отклонённый или непроверенный патч.
- Проверить существующий конвейер на трёх и более файлах; исправлять только обнаруженные препятствия этому сценарию.
- Добавить необязательный уровень рассуждений API и пересчёт длин hunk модельного diff при сохранении строгих проверок.
- Подготовить инструкцию дня 34, запись экрана и черновики сдачи с фактическими результатами.

## Capabilities

### New Capabilities

- `project-file-demo`: повторяемая демонстрация исследования и изменения файлов проекта по цели.

### Modified Capabilities

В существующем конвейере появляется независимое ревью до подтверждения записи; контракты подтверждения и undo сохраняются.

## Impact

Сценарий `scripts/day34_demo.py`, интеграционные проверки, `docs/day34-project-files.md`, README и AGENTS.
Используются существующие AssistantSession, MCP, TaskPipeline и ProjectChanges. Новые зависимости не нужны.
Код проекта WebDavClient и репозитория челленджа не меняется. Предлагаемый следующий релиз — v0.34 после v0.33; тег и публикация требуют отдельного разрешения.
