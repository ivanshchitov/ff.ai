# День 31: ассистент, понимающий проект

Источник: `../ai-advent-challenge-9/week7/day31/README.md`.
Решение: ff.ai. Требования: README и docs в RAG, текущая git-ветка через MCP,
`/help` отвечает на вопросы о структуре. Формат результата — видео и код.

## Использование

```bash
/path/to/ff.ai/ff-ai.py --repo /path/to/aurora-project --domain aurora-qt5
```

В TUI либо в web-композере:

```text
/rag-code index
/rag-code retrieval baseline
/rag-code tune before=20 after=8
/help
/help Как устроен проект и где находятся основные компоненты?
/help Какие соглашения по написанию кода приняты в проекте?
/rag-code trace
/usage
```

README, Markdown в docs и исходники входят в общий локальный корпус. Индекс
находится вне проекта. Ответ сопровождается доставленными источниками с путями
и строками; в свободном формате проверяется дословная цитата. Enhanced-режим
сохраняет переформулировку и модельный отбор; baseline ищет локально без них.

Для каждого `/help` собственный MCP-сервер проекта получает
`repo_git(args="status --short --branch")`. Журнал показывает свежий результат,
включая detached HEAD и состояние без первого коммита. При отказе MCP ветка
считается неизвестной; при недоступном корпусе нельзя утверждать структуру без
источников. Пересоберите stale-индекс через `/rag-code index`.
Ручные правки, удаление и добавление файлов проверяются перед `/help`, а не только
через журнал операций агента. Git-чтение не обновляет служебный индекс проекта.

Команда не запускает разработку даже при просьбе изменить файлы. Ответ сохраняется
в истории и общем учёте расхода. TUI и web используют единый обработчик сессии.

## Сценарий демо

Использовать временную копию WebDavClient и отдельное состояние FFAI;
исходный проект и настоящая история не участвуют в демонстрации. Перед живым
прогоном проверить документы и доставляемые фрагменты на секреты без печати значений.

1. Показать сборку корпуса README, docs и исходников.
2. Задать вопрос о структуре; показать ответ, источники README и MCP git-контекст.
3. Задать вопрос о соглашениях; показать источник `docs/coding_conventions.md`.
4. Показать трассировку доставки и фактический расход двух ответов.

Для воспроизводимой записи выбран baseline: первый вопрос содержит маркеры
«README Project structure» и названия основных каталогов, второй — путь
`docs/coding_conventions.md` и термины форматирования. В трассировке виден токенный
поиск; модельный отбор не участвует в выборе источников. `/help` поддерживает
также enhanced и сохраняет выбранный пользователем режим.
Штатный бюджет ответа — 4050 токенов при настройке 1000 слов. Краткость в демо
задаётся просьбой в вопросе, чтобы рассуждения модели не исчерпали бюджет.

Черновики README челленджа и release notes готовятся отдельно в `videos/`.
