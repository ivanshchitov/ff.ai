# Поддержка пользователей WebDavClient

Демонстрационный набор для ff.ai: продуктовая документация настоящая,
пользователи и обращения вымышленные. Исходный WebDavClient не изменяется.
Руководство скопировано из `WebDavClient/docs/manual.ru.md`, commit `2487b99d238cc277eb87dcf8f98861a8e789c745`.
FAQ по OAuth составлен по коду того же commit; остальные ответы — по руководству.
Не содержит паролей, токенов или контактных данных. Адрес example.test не настоящий.

При запуске ff.ai выбрать `--domain product-support`, сначала `/rag-code index`.
Команда: `/support TICKET-101 Почему не получается войти и что мне сделать?`.
Повторить для TICKET-102. Для TICKET-103 спросить, как оставить оригинал на сервере.
Подробный запуск описан в `docs/day33-user-support.md` репозитория ff.ai.
