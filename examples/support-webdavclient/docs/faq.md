# FAQ поддержки WebDavClient

## Яндекс.Диск: повторный вход и expired_token

Если в обращении Яндекс.Диска указан expired_token или зафиксировано истечение срока
токена, приложение открывает страницу OAuth для повторной авторизации. Завершите
вход на странице Яндекса и повторите открытие хранилища. Пароль и токен не передавайте
поддержке. При повторной ошибке сообщите её текст без учётных секретов.
Не считайте истечение токена причиной любой ошибки входа без диагностических данных.

Источник: производная документация по `core/controllers/connectioncontroller.cpp`,
метод `startConnection(Token)`, и `app/qml/pages/AuthorizationLoadingPage.qml`,
обработчик `onInvalidToken`, в исходном WebDavClient (commit указан в README).

## Обычный WebDAV-сервер: полная ссылка и HTTP_404

Для создания учётной записи обычного WebDAV-сервера нужна полная ссылка к
WebDAV-серверу, имя пользователя и пароль сервера. Главная страница сайта может
отличаться от WebDAV-адреса. Используйте адрес, указанный администратором.
Если в тикете указан HTTP_404 и введённая ссылка отличается от предоставленной,
проверьте ссылку; это вероятная причина по данным обращения, а не доказательство
для любого 404. Путь /dav/ из примера тикета не является универсальным.
OAuth Яндекса не используется для обычного WebDAV-сервера.

Источник: `docs/manual.ru.md`, раздел «Создание учётной записи с другим WebDAV-сервером»;
разбор введённого URL подтверждается `core/controllers/connectioncontroller.cpp`.

## Скачать или Переместить на устройство

Чтобы файл остался на сервере, выберите Скачать в контекстном меню файла и
укажите каталог на устройстве. Переместить на устройство отличается от скачивания:
после выполнения выбранный файл или каталог удаляется с удалённого сервера.
Не выбирайте перемещение, если хотите сохранить удалённый оригинал.

Источник: `docs/manual.ru.md`, раздел «Контекстные действия с файлами/каталогами».

## Как обновить список файлов после успешного подключения

Откройте верхнее вытягиваемое меню и нажмите Обновить папку. Список файлов и
каталогов текущего каталога обновится. Если подключение уже работает, прежняя
ошибка добавления учётной записи сама по себе не требует повторной настройки.

Источник: `docs/manual.ru.md`, раздел «Действия с текущим каталогом».
