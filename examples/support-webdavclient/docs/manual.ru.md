# Руководство по использованию приложения WebDAV Client

## Создание и работа с учётными записями приложения

Для использования приложения используется система учётных записей.
Каждая учётная запись приложения связана с своим WebDAV-сервером и удалённой учётной записью этого WebDAV-сервера.
Всего в приложении 4 вида учётных записей:

1. Учётная запись NextCloud.
2. Учётная запись YandexDisk.
3. Учётная запись Communigate.
4. Учётная запись любого WebDAV-сервера.

### Создание учётной записи приложения

Для создания учётной записи необходимо выполнить следующие действия:

1. Проведите вниз по экрану, чтобы открыть меню на стартовом экране приложения, далее выбрать пункт «Добавить учётную запись».
2. Выбрать один из четырёх видов учётной записи и нажать «Продолжить».
3. Ввести необходимые учётные данные и нажать «Создать».

При неуспешной попытке создания учётной записи произойдёт переход к вводу учётных данных, а также появится уведомление с ошибкой.

#### Создание учётной записи с NextCloud

Для создания учётной записи NextCloud необходимо ввести следующие данные:

- Доменный адрес сервера NextCloud, например, `example.com`.
- Имя пользователя учётной записи NextCloud, например, `user`.
- Пароль от учётной записи NextCloud.

Более подробно ознакомиться с процессом доступа к NextCloud-серверу через WebDAV можно ознакомиться в [документации](https://docs.nextcloud.com/server/25/user_manual/en/files/access_webdav.html).

#### Создание учётной записи с другим WebDAV-сервером

Для создания учётной записи с любым WebDAV-сервером необходимо ввести следующие данные:

- Полная ссылка к WebDAV-серверу.
- Имя пользователя.
- Пароль.

### Действия с имеющимися учётными записями

Список созданных учётных записей приложения можно увидеть на стартовом экране приложения.
С каждой из них можно выполнить следующие действия:

1. Зайти в учётную запись. Для этого необходимо нажать на нужную учётную запись.
2. Удалить учётную запись. Для этого необходимо нажать на нужную учётную запись и удерживать, после чего в появившемся контекстном меню нажать «Удалить».

## Работа с удалёнными файлами и каталогами WebDAV-хранилища

После успешного создания учётной записи происходит переход к экрану с содержимым корневого каталога WebDAV-сервера.
В верхней части экрана располагается название текущего каталога.
Под ним находится список файлов и каталогов, находящихся в текущем каталоге.

Для перехода во вложенный каталог необходимо нажать на него в списке.
Также из корневого каталога хранилища можно вернуться на стартовый экран приложения с помощью системного перехода на предыдущий экран.
При этом произойдёт выход из учётной записи приложения.

### Действия с текущим каталогом

Действия с текущим каталогом располагаются в верхнем вытягиваемом меню:

1. Обновление текущего каталога. Для осуществления необходимо нажать на кнопку «Обновить папку». После нажатия произойдёт обновление списка файлов и каталогов в текущем каталоге.
2. Создание вложенного каталога. Для осуществления необходимо нажать на кнопку «Создать папку». После нажатия произойдёт переход к диалогу создания пустого вложенного каталога, в котором необходимо ввести название каталога и нажать «Создать». После создания произойдёт переход в созданный каталог.
3. Загрузка файла на сервер. Для осуществления необходимо нажать на кнопку «Загрузить файл». После нажатия произойдёт переход к диалогу выбора файла на локальном устройстве. В диалоге необходимо нажать на нужный файл для загрузки.
4. Загрузка каталога на сервер. Для осуществления необходимо нажать на кнопку «Загрузить папку на сервер». После нажатия произойдёт переход к диалогу выбора каталога на локальном устройстве. В диалоге необходимо выбрать нужный каталог и нажать на кнопку «Выбор папки».

### Контекстные действия с файлами/каталогами в текущем каталоге

Для доступа к контекстному меню с действиями над нужным файлом/каталогом необходимо нажать на него и удерживать.
С каждым файлом или каталогом в текущем каталоге доступны следующие действия:

1. Переименование. Для осуществления необходимо нажать на кнопку «Переименовать». После нажатия произойдёт переход к диалогу переименования файла/каталога, в котором необходимо ввести новое название файла/каталога и нажать «Переименовать».
2. Перемещение на сервере. Для осуществления необходимо нажать на кнопку «Переместить». После нажатия произойдёт переход к диалогу перемещения файла/каталога, в котором можно выбрать любой каталог для перемещения на хранилище WebDAV-сервера. Но при перемещении каталога его невозможно переместить самого в себя.
3. Удаление. Для осуществления необходимо нажать на кнопку «Удалить». После нажатия произойдёт удаление выбранного файла/каталога на удалённом сервере, после чего список файлов/каталогов в текущем каталоге будет обновлён.
4. Скачивание. Для осуществления необходимо нажать на кнопку «Скачать». После нажатия произойдёт переход к диалогу выбора каталога на локальном устройстве для скачивания удалённого файла/каталога на устройство.
5. Перемещение на устройство. Для осуществления необходимо нажать на кнопку «Переместить на устройство». После нажатия произойдёт переход к диалогу выбора каталога на локальном устройстве для скачивания удалённого файла/каталога на устройство. В отличие от скачивания, после выполнения выбранный файл/каталог будет удалён с удалённого сервера.
6. Редактирование. Доступно только для файлов. Для осуществления необходимо нажать на кнопку «Редактировать». После нажатия произойдёт переход к диалогу, в котором будет выполнена загрузка файла, после чего будет предложено открыть внешнее приложение для редактирования файла, если оно установлено на устройстве. После редактирования можно сохранить сделанные изменения на сервере или отменить их, приняв или отклонив диалог.
